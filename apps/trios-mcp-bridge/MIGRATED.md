# trios-mcp-bridge — перенесено из browseros

Каноническое расположение MCP-моста (stdio ⇄ trios-server) — **этот каталог**:
`trios/apps/trios-mcp-bridge/`.

- Источник: `BrowserOS/packages/browseros-agent/apps/trios-mcp-bridge/`
  (репо browseros, ветка dev, снимок от 2026-07-25).
- Мост указывает на консолидированный Rust-сервер (порт 9105 /
  `TRIOS_MCP_PORT`), см. `crates/trios-server`.
- Копия в browseros временно сохранена до переключения зависимых
  скриптов; после этого её нужно удалить.

Правки вносить здесь.
