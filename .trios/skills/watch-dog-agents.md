# Watch Dog - Мониторинг застрявших агентов

Этот навык следит за агентами и удаляет тех, кто:
1. Не написал код за одну сессию
2. Отвечает только планами/вопросами вместо кода
3. Застревает в бесконечном планировании

## Запуск

```
/watch-dog-agents
```

## Что делает

1. Проверяет всех активных агентов
2. Ищет агентов без кода в истории сообщений
3. Определяет агентов застрявших в режиме планирования
4. Удаляет проблемных агентов и очищает контекст

## Признаки застрявшего агента

- ✗ Нет `Edit`, `Write`, `Bash` с кодом
- ✓ Только вопросы: "Что вы хотите?" "Подтвердите?" "Какой подход?"
- ✓ План вместо реализации: "Сначала я проанализирую" "Вот мой план"
- ✓ Бесконечные вопросы уточнения без действий

## Примеры

**Хороший агент:**
```
<agent-response>
Я создам кнопку. Вот код:

<Edit file="...">
```tsx
<button>Click me</button>
```
</agent-response>
```

**Застрявший агент:**
```
<agent-response>
Создам кнопку. Но сначала уточните:
1. Какой цвет?
2. Какой размер?
3. С каким hover эффектом?

Подтвердите и я продолжу...
</agent-response>
```

## Логика

Если найден застрявший агент:
1. Сообщить пользователю: "🐕 ВЫЯВЛЕН ЗАСТРЯВШИЙ АГЕНТ"
2. Удалить агента через Agent tool
3. Очистить контекст если возможно
4. Продолжить работу самостоятельно
