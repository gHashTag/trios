\chapter{Coq Citation Map (R5-Honest Full Catalogue, Consolidated)}
\label{app:F}

This appendix is the \textbf{single source of truth} for the consolidated Coq formal-proof citation map across the entire Trinity ecosystem: \texttt{gHashTag/trios} (PhD theorem dir, Trinity-Clara runtime proofs, Trinity-Chat invariants), \texttt{gHashTag/t27} (mirrored upstream Trinity tree), and the cross-cutting bridge proofs.
Numbers are produced mechanically by \texttt{scripts/gen\_appendix\_f.py} (regenerated every Coq commit) from \texttt{phd\_proofs\_inventory\_v2.json}, which is itself produced by deduplicating SHA-1 hashes of every \texttt{*.v} file across the three repositories.
All counts are \emph{verbatim} from the \texttt{*.v} files.
\textbf{R5 honesty} is preserved: every \texttt{Admitted.} closure is reported as such, never silently flipped to \texttt{Qed.}

\section{Honest-admitted budget}

As of this build, exactly 32 \texttt{Admitted.} closures remain in the consolidated corpus.
All are flagged in the per-bucket tables above (\texttt{Adm} column).
The R5 audit gate (\texttt{phd-monograph-auditor}, cron \texttt{15 */2 * * *}) compares this number against \filepath{assertions/igla\_assertions.json::admitted\_budget.max} on every cycle.
Any silent flip from \texttt{Admitted} to \texttt{Qed} (or addition of a new \texttt{Admitted} without ledger entry) triggers a \texttt{RED} status on issue \#109.

\section{Provenance and reproducibility}

\begin{itemize}
  \item \textbf{Inventory generator:} \filepath{scripts/build\_full\_inventory.py} (admin one-shot; walks all \texttt{*.v} under the three repository roots, deduplicates by SHA-1, classifies by path).
  \item \textbf{Appendix renderer:} \filepath{scripts/gen\_appendix\_f.py} (reads the JSON inventory, emits this appendix verbatim).
  \item \textbf{Compile gate:} \texttt{coqc} is invoked per file in CI workflow \texttt{coq-verify.yml}; any failure blocks the PR.
  \item \textbf{Runtime bridge:} \filepath{assertions/igla\_assertions.json} is the single source of truth between Coq proofs and Rust runtime guards (see \texttt{coq-runtime-invariants v1.1}).
  \item \textbf{RAG ingestion:} every theorem entry point in this appendix becomes a separate chunk in \texttt{ssot.embeddings} via \texttt{cargo run -p trios-phd --bin ingest\_rag\_chunks}, keeping the formal proofs semantically searchable at defense time.
\end{itemize}
