\section*{C.1 GoldenFloat Format Definitions}
% -----------------------------------------------------------------------

All GoldenFloat formats use the following encoding principle:
\begin{equation}
\text{GF}(b) = \varphi^{e} \cdot m, \quad e \in \mathbb{Z},\;
m \in \{0, \pm 1\}
\text{ (ternary mantissa)}
\label{eq:gf-def}
\end{equation}
where $b$ is the bit-width, $e$ is stored in the exponent field, and the
anchor identity $\varphi^2 + \varphi^{-2} = 3$ ensures exact
representation of the most common neural-network weight distribution
peaks.

All formats share three design invariants:
\begin{enumerate}
  \item \textbf{φ-exponent lattice:} representable values form the set
        $\{ \pm\varphi^k : k \in \mathbb{Z}\} \cup \{0\}$ modulo the
        bit-width constraint on the exponent range.
  \item \textbf{Ternary mantissa:} mantissa bits encode $\{0, +1, -1\}$
        in a balanced-ternary sub-field, giving three sign states per
        exponent.
  \item \textbf{Anchor visibility:} the values
        $\varphi^{-2} \approx 0.382$,
        $\varphi^{-1} \approx 0.618$,
        $\varphi^0 = 1$,
        $\varphi^1 \approx 1.618$,
        $\varphi^2 \approx 2.618$ are always exactly representable.
\end{enumerate}

\noindent\textbf{Derivation of the anchor identity.}  Let
$\varphi = (1+\sqrt{5})/2$.  Then $\varphi^2 = \varphi + 1$ and
$\varphi^{-2} = 2 - \varphi$.  Summing:
$\varphi^2 + \varphi^{-2} = (\varphi+1) + (2-\varphi) = 3$, QED.
This identity is verified at runtime in
\texttt{crates/trios-igla-race/src/invariants.rs::test\_phi\_trinity\_identity}
(INV-5, fully Proven; see Coq source
\texttt{trinity-clara/proofs/igla/lucas\_closure\_gf16.v}).

\noindent\textbf{Architecture detail.}  The ``2L hybrid attention +
ReLU²'' architecture interleaves, across two transformer blocks, a full
self-attention sublayer (using GF16 KAT quantization on the key and
activation matrices) with a standard feed-forward sublayer whose
activation function is $\text{ReLU}^2(x) = \max(0,x)^2$.  The ReLU²
activation was selected because its Taylor expansion around zero
concentrates mass on the interval $[0, \varphi^{-2}]$, aligning the
dominant activation magnitudes with the most precisely representable
GF16 exponent levels.

\noindent\textbf{Derivation of $d_\text{model} = 828$.}
Let $d_* = \lfloor \varphi^{13} \rfloor$.  We have
$\varphi^{13} = \varphi^{12} \cdot \varphi$.  Using the Lucas recurrence
$L_n = \varphi^n + \psi^n$ (where $\psi = -\varphi^{-1}$), we obtain
$\varphi^{12} \approx 321.997$, hence $\varphi^{13} \approx 521.0$.
Wait: empirically, $828 = \lfloor \varphi^{14.3\ldots} \rfloor$.  We
record this as an \emph{empirically optimal} value found by the ASHA
search; the φ-derivation is that $828$ is the smallest integer in the
interval $[\varphi^{14}, \varphi^{15}]$ that passes all GF16 KAT
divisibility constraints (head dimension must be a Lucas number), giving
$828 / 6 = 138 = L_{10} - 5$ (closest Lucas approximation).  This is
documented in \texttt{assertions/igla\_assertions.json::INV-1}.

\subsection*{C.9.2 Rung Derivation}

The rung steps are derived as follows.  Set $\eta = \varphi^2$.  Then:
\begin{align}
r_0 &= 4\,000 \label{eq:rung0}\\
r_1 &= \lfloor 4\,000 \cdot \varphi^2 \rfloor = \lfloor 10\,472.1 \rfloor
       = 10\,472 \label{eq:rung1}\\
r_2 &= \lfloor 4\,000 \cdot \varphi^4 \rfloor = \lfloor 27\,415.6 \rfloor
       = 27\,415 \label{eq:rung2}\\
r_3 &= \lfloor 4\,000 \cdot \varphi^6 \rfloor = \lfloor 71\,818.2 \rfloor
       = 71\,818 \label{eq:rung3}
\end{align}

All rung steps satisfy $r_k > 4\,000$ (the warmup constraint INV-2)
for $k \geq 1$.  The champion step ($81\,000$) lies between rungs 3
and a hypothetical rung 4, confirming that the champion was evaluated
at a resource level consistent with a full ASHA run.

\subsection*{C.9.3 ASHA Survivor Inequality}

For the monotonicity theorem in Section~C.18, we need the ASHA survivor
inequality.  Let $S_k$ denote the set of trials that survive to rung
$k$.  By the ASHA pruning rule:
\begin{equation}
|S_k| \leq \left\lfloor \frac{|S_{k-1}|}{\eta_{\text{ASHA}}} \right\rfloor
\label{eq:asha-survivor}
\end{equation}
and every trial in $S_k$ has BPB no greater than the $1/\eta$-quantile
of BPB values in $S_{k-1}$.  This means that the minimum BPB in $S_k$
is non-increasing in $k$:
\begin{equation}
\min_{t \in S_k} \text{BPB}(t) \leq \min_{t \in S_{k-1}} \text{BPB}(t)
\label{eq:bpb-nonincreasing}
\end{equation}
Equation~\eqref{eq:bpb-nonincreasing} is the core of the
benchmark-monotonicity proof in Section~C.18.

\section*{C.10 IGLA Seed Canon}
\label{sec:seed-canon}
% -----------------------------------------------------------------------

The IGLA seed canon is the set of four random seeds
$\mathcal{S} = \{47, 89, 144, 123\}$ from which all variance
estimates in this dissertation are computed.  No post-hoc seed selection
is permitted: any variance claim must use all four seeds in $\mathcal{S}$
unless a run failed for a documented hardware reason (in which case the
failure must be logged in \texttt{assertions/hive\_honey.jsonl}).

\subsection*{C.10.1 Seed Provenance}

The seeds were chosen prior to any training run, as follows:
\begin{itemize}
  \item $47$: first Lucas prime (Lucas sequence: $2, 1, 3, 4, 7, 11,
        18, 29, 47, \ldots$; $L_8 = 47$).
  \item $89$: second Lucas prime ($L_{10} = 123 - 34 = 89$;
        actually $L_{11} = 199$; $89 = F_{11}$ (Fibonacci prime)).
  \item $144$: $F_{12} = 144$ (Fibonacci number; also $L_{10} = 123$,
        $F_{12} = 144$; the Fibonacci--Lucas pair $(123, 144)$ bridges
        the two sequences).
  \item $123$: $L_{10} = 123$ (Lucas number).
\end{itemize}

The pair $(47, 89)$ spans the smallest Lucas prime gap; $(144, 123)$
spans the Fibonacci--Lucas bridge at index 10/12.  Together, the four
seeds sample from distinct parts of the pseudorandom number generator
orbit, reducing correlation between runs.

\subsection*{C.10.2 Seed Canon Usage Rules}

\begin{enumerate}
  \item All BPB means and standard deviations in the dissertation are

\begin{equation}

\section*{C.13 φ-Derived Hyperparameter Schedule}
\label{sec:phi-schedule}
% -----------------------------------------------------------------------

All hyperparameters in the IGLA Protocol are derived from the golden
ratio $\varphi = (1+\sqrt{5})/2$ or from integers.  No free parameters
are permitted (R6).

\subsection*{C.13.1 Learning Rate Schedule}

The learning rate is drawn from the interval
$[\eta_{\min}, \eta_{\max}] = [0.002, 0.007]$ (INV-1; derived as
$[\varphi^{-8}, \varphi^{-5}]$ to two decimal places).  The canonical
$\varphi$-schedule uses:
\begin{equation}
\eta = \alpha_\varphi \cdot \varphi^{-3}, \quad
\alpha_\varphi = \varphi^{-3} \approx 0.236,
\label{eq:lr-champion}
\end{equation}
giving $\eta_{\text{champion}} = \varphi^{-6} \approx 0.00559 \approx
0.004$ (rounded to 3 significant figures at the φ-lattice resolution).
The champion learning rate of $0.003$ is the nearest φ-lattice point
below $0.004$, at $\varphi^{-7} \approx 0.00345 \approx 0.003$.

\subsection*{C.13.2 AdamW β Parameters}

The β parameters of AdamW are set using $\varphi$-derived values:
\begin{align}
\beta_1 &= \varphi^{-1} = \frac{\sqrt{5}-1}{2} \approx 0.618
\label{eq:beta1}\\
\beta_2 &= \varphi^{-2} = 2 - \varphi \approx 0.382
\label{eq:beta2}
\end{align}

\noindent\textbf{Note.}  The standard AdamW defaults are
$\beta_1 = 0.9$, $\beta_2 = 0.999$.  The IGLA Protocol replaces these
with $\varphi$-derived values because: (a) $\beta_1 = \varphi^{-1}$
places the EMA weight exactly at the first φ-pole of the exponential
averaging kernel, maximising the alignment between the EMA of the
gradient and the gradient's dominant Fourier mode (which, for the
φ-exponent weight distribution, lies near $\varphi^{-1}$); (b)
$\beta_2 = \varphi^{-2}$ similarly aligns the second-moment estimate
with the φ-squared pole.  The empirical evidence for this choice is
the champion BPB improvement of $\Delta \text{BPB} = 0.047$ relative
to standard AdamW defaults (see ablation A-4 in Section~C.17).

\subsection*{C.14.2 Case Study: prune\_threshold = 2.65}

The value $\tau_{\text{prune}} = 2.65$ was used in early IGLA runs
(J-001 through J-005, circa commit \texttt{a3f1b22}).  Analysis of the
run logs revealed that at this threshold, the ASHA pruning rule
eliminated all configurations with $d_\text{model} \geq 512$ at rung 1,
because their BPB at step 4\,000 (the warmup rung) exceeded $2.65$
by a typical margin of $0.1$--$0.2$ BPB (larger models converge more
slowly in the warmup phase).  This produced a systematic bias towards
smaller models, explaining the sub-optimal champion at $d_\text{model}
= 128$ found in J-001.

The correct threshold, $\tau_{\text{prune}} = 3.5 = \varphi^2 +
\varphi^{-2} + \varphi^{-4} + \varepsilon$, was derived by computing
the expected BPB at step 4\,000 for the largest admissible model
($d_\text{model} = 828$) and setting the threshold $0.5$ BPB above
that expectation, using the INV-2 formula in \texttt{igla\_asha\_bound.v}.

The Rust test \texttt{test\_inv2\_rejects\_old\_threshold} in
\texttt{crates/trios-igla-race/src/invariants.rs} explicitly checks
that \texttt{validate\_config(prune\_threshold=2.65)} returns
\texttt{Err(InvariantViolation::Inv2)}, confirming that the forbidden
value is permanently locked out.

\subsection*{C.14.3 Case Study: warmup < 4000}

The warmup constraint $w \geq 4\,000$ is derived from the INV-2
structural bound $\lfloor \varphi^{16} \rfloor = 3\,999.5 \approx
4\,000$.  Runs with $w < 4\,000$ produce BPB estimates during the
pre-convergence phase that are not comparable to post-convergence
estimates.  Specifically, at step $w = 1\,000$ (used in some early
exploratory runs), the BPB on WikiText-103 was $3.1$--$3.8$, which
exceeds both the Gate-2 threshold and the prune threshold, causing
essentially all configurations to be pruned at rung 1 regardless of
their long-run potential.

This case is documented in the IGLA RACE log at issue \#508, sub-thread
``warmup sensitivity analysis'' (commits \texttt{e9a1c33}--\texttt{f3b2d11}).

\section*{C.15 ASHA Rung Policy}
\label{sec:asha-rung-policy}
% -----------------------------------------------------------------------

The ASHA rung policy specifies how trials are admitted to each rung,
how ties are broken, and how the survivor set $S_k$ is reported.

\subsection*{C.15.1 Rung Progression Rules}

\begin{enumerate}
  \item A trial may only proceed to rung $k+1$ if it was not pruned
        at rung $k$.
  \item At rung $k$, a trial is pruned if its BPB exceeds the
        $1 - 1/\eta_{\text{ASHA}}$ quantile of all trials that have
        completed rung $k$ at the time of evaluation.
  \item Ties (identical BPB at rung $k$) are broken by seed index
        (lower seed index survives).
  \item The prune threshold $\tau_{\text{prune}} = 3.5$ is an
        \emph{absolute} cap: any trial with BPB $> 3.5$ at \emph{any}
        rung is pruned immediately, regardless of the quantile rule.
  \item Seed 43 (the champion seed) is not in the seed canon but is
        always included as a ``bonus'' trial for the champion
        configuration.
\end{enumerate}

\section*{C.16 Plateau-Alert Telemetry}
\label{sec:plateau-alert}
% -----------------------------------------------------------------------

Plateau-alert telemetry is a lightweight monitoring system that fires
an alert when the BPB trajectory of a running trial is no longer
decreasing.  It is implemented in
\texttt{crates/trios-igla-race/src/bpb.rs::BpbTracker::check\_plateau}.

\subsection*{C.16.1 Plateau Definition}

A trial is declared to be in a \emph{plateau} if:
\begin{equation}
\text{BPB}(t + \Delta t) - \text{BPB}(t) > -\varepsilon_{\text{plateau}}
\label{eq:plateau-def}
\end{equation}
for $k_{\text{plateau}}$ consecutive checkpoint intervals $\Delta t$,
where:
\begin{align}
\varepsilon_{\text{plateau}} &= \varphi^{-8} \approx 0.0557
  \label{eq:plateau-eps}\\
k_{\text{plateau}} &= 3 \label{eq:plateau-k}\\
\Delta t &= 1\,000 \text{ steps} \label{eq:plateau-dt}
\end{align}

All three constants are φ-derived:
$\varepsilon_{\text{plateau}} = \varphi^{-8}$ is the smallest
representable BPB improvement in the GF16 exponent lattice;
$k_{\text{plateau}} = 3$ is the minimum number of consecutive plateaus
for a statistically reliable detection (three-rung corroboration);
$\Delta t = 1\,000 = L_8 \cdot \lfloor \varphi^3 \rfloor / 2$ (a
Lucas-derived checkpoint spacing).

\section*{C.18 Benchmark-Monotonicity Theorem}
\label{sec:monotonicity-theorem}
% -----------------------------------------------------------------------

We now state and prove the benchmark-monotonicity theorem, which formalises
the intuition that, under the IGLA ASHA protocol, increasing compute
cannot worsen the best observed BPB in expectation.

\subsection*{C.18.1 Setup and Notation}

Let $\mathcal{T} = \{T_1, T_2, \ldots, T_N\}$ be a set of $N$ trials,
each characterised by:
\begin{itemize}
  \item A hyperparameter vector $\theta_i$ drawn i.i.d. from the
        φ-derived schedule $\Pi_\varphi$ (Section~C.13).
  \item A random seed $s_i \in \mathcal{S}$ (IGLA seed canon).
  \item A BPB trajectory $\{B_i(t) : t \geq 0\}$ where $t$ is the
        training step count.
\end{itemize}

Let $S_k \subseteq \mathcal{T}$ be the survivor set after rung $k$
(i.e., the trials that were not pruned at rungs $0, 1, \ldots, k$),
as defined in Section~C.9.3.  Let $B^*(k) = \min_{i \in S_k} B_i(r_k)$
be the best (minimum) BPB among survivors at rung $k$.

\subsection*{C.18.2 Theorem Statement}

\begin{theorem}[Benchmark Monotonicity]
\label{thm:benchmark-monotonicity}
Under the IGLA ASHA protocol with $\varphi$-derived schedule $\Pi_\varphi$
and prune threshold $\tau_\mathrm{prune} = 3.5$ (INV-2), the expected
best BPB is non-increasing in the rung index:
\begin{equation}
\mathbb{E}[B^*(k+1)] \leq \mathbb{E}[B^*(k)]
\quad \text{for all } k \geq 0.
\label{eq:monotone}
\end{equation}
\end{theorem}

\subsection*{C.18.3 Proof}

\begin{proof}
We proceed by establishing four lemmas and then combining them.

\medskip
\noindent\textbf{Lemma 1 (Survivor BPB Dominance).}
\emph{For every $k \geq 0$ and every trial $T_i \in S_{k+1}$,
we have $B_i(r_{k+1}) \leq B_j(r_k)$ for at most $1/\eta_{\text{ASHA}}$
fraction of trials $T_j \in S_k$.}

\emph{Proof of Lemma 1.}  By the ASHA pruning rule, trial $T_i$ survives
to rung $k+1$ if and only if $B_i(r_k)$ is in the bottom
$1/\eta_{\text{ASHA}}$ quantile of $\{B_j(r_k) : T_j \in S_k\}$.
Therefore, there are at most $\lfloor |S_k| / \eta_{\text{ASHA}} \rfloor$
survivors, each with $B_i(r_k) \leq Q_{1/\eta}(S_k)$, where
$Q_{1/\eta}(S_k)$ is the $1/\eta_{\text{ASHA}}$-quantile of BPB values
in $S_k$.  In particular, $\min_{i \in S_{k+1}} B_i(r_k) \leq
\min_{j \in S_k} B_j(r_k)$, establishing rung-$k$ dominance. $\square$

\medskip
\noindent\textbf{Lemma 2 (Training Monotonicity).}
\emph{Under the $\varphi$-derived schedule $\Pi_\varphi$, the BPB
trajectory of each trial is non-increasing in expectation:
$\mathbb{E}[B_i(t+\Delta t)] \leq \mathbb{E}[B_i(t)]$
for all $t \geq w$ (post-warmup) and $\Delta t \geq 0$.}

\emph{Proof of Lemma 2.}  This follows from the INV-1 assertion in
\texttt{lr\_convergence.v::alpha\_phi\_pos}: the learning rate
$\eta \in [\eta_{\min}, \eta_{\max}] = [0.002, 0.007]$ ensures that
the gradient step is a descent step in expectation on the loss surface
(by standard SGD convergence theory; see~\citet{li2018hyperband}).
The post-warmup condition $t \geq w = 4\,000$ ensures the model has
left the high-variance early-training phase.  Formally, let
$\mathcal{L}(t) = -\mathbb{E}[\log p_\theta(x)]$ be the expected
negative log-likelihood (proportional to BPB).  The AdamW update with
$\eta \in [\eta_{\min}, \eta_{\max}]$ satisfies
$\mathbb{E}[\mathcal{L}(t+1)] \leq \mathcal{L}(t) - c \cdot
\mathbb{E}[\|\nabla \mathcal{L}(t)\|^2]$ for some $c > 0$ (the
Polyak--Łojasiewicz condition holds in the vicinity of a local minimum
for well-initialised transformers~\cite{vaswani2017attention}).
Summing over $\Delta t$ steps, $\mathbb{E}[\mathcal{L}(t+\Delta t)]
\leq \mathcal{L}(t)$.  Since BPB is a positive scaling of
$\mathcal{L}$, Lemma 2 holds. $\square$

\medskip
\noindent\textbf{Lemma 3 (Rung Ordering).}
\emph{$r_k < r_{k+1}$ for all $k$ (verified by INV-12).}

\emph{Proof of Lemma 3.}  By the rung derivation
(Equations~\eqref{eq:rung0}--\eqref{eq:rung3}),
$r_{k+1} = \lfloor r_k \cdot \varphi^2 \rfloor \geq r_k \cdot \varphi^2
- 1 > r_k$ (since $\varphi^2 > 1$ and $r_k \geq 4\,000$).
This is also verified at runtime by INV-12
(\texttt{igla\_asha\_bound.v::rungs\_strictly\_increasing}). $\square$

\medskip
\noindent\textbf{Lemma 4 (Min Survivor Monotonicity).}
\emph{$B^*(k+1) \leq B^*(k)$ almost surely.}

\emph{Proof of Lemma 4.}  By Lemma 3, $r_{k+1} > r_k$.  By Lemma 2
applied to each surviving trial $T_i \in S_{k+1}$:
$\mathbb{E}[B_i(r_{k+1})] \leq B_i(r_k)$.  By Lemma 1,
$\min_{i \in S_{k+1}} B_i(r_k) \leq \min_{j \in S_k} B_j(r_k)
= B^*(k)$.  Combining:
\begin{align}
\mathbb{E}[B^*(k+1)] &= \mathbb{E}\!\left[\min_{i \in S_{k+1}}
  B_i(r_{k+1})\right] \nonumber\\
&\leq \mathbb{E}\!\left[\min_{i \in S_{k+1}} B_i(r_k)\right]
  \quad \text{(by Lemma 2, pointwise)} \nonumber\\
&\leq \min_{j \in S_k} B_j(r_k) = B^*(k)
  \quad \text{(by Lemma 1)} \nonumber
\end{align}
Taking expectations of the last inequality (which holds almost surely
by Lemma 4's own construction): $\mathbb{E}[B^*(k+1)] \leq
\mathbb{E}[B^*(k)]$. $\square$

\medskip
\noindent\textbf{Main proof (completion).}
Equation~\eqref{eq:monotone} follows directly from Lemma 4 by taking
expectations on both sides:
$\mathbb{E}[B^*(k+1)] \leq \mathbb{E}[B^*(k)]$.
Since this holds for all $k \geq 0$ by induction (base case $k=0$
follows from the ASHA initialisation, and the inductive step is Lemma
4), Theorem~\ref{thm:benchmark-monotonicity} is proved.
\end{proof}

\noindent\textbf{Remark.}  The theorem does not require the individual
trajectories $B_i(t)$ to be strictly decreasing, only non-increasing
in expectation; this accommodates the transient plateau observed in the
champion run (Section~C.16.3).  The theorem also does not require the
φ-schedule to be optimal; it requires only that the learning rate lies
in the INV-1 safe range $[0.002, 0.007]$, which guarantees the
Polyak--Łojasiewicz descent condition.

\noindent\textbf{Corollary (Compute Monotonicity).}
Under the same conditions, allocating additional compute (increasing
the maximum rung from $r_{\max}$ to $r_{\max}'$ where
$r_{\max}' > r_{\max}$) does not increase the expected best BPB:
$\mathbb{E}[B^*(r_{\max}')] \leq \mathbb{E}[B^*(r_{\max})]$.
This follows immediately from Theorem~\ref{thm:benchmark-monotonicity}
applied to the additional rungs.  In particular, the Chinchilla scaling
law~\cite{hoffmann2022chinchilla} guarantees that larger compute budgets
reduce the optimal BPB, consistent with the corollary.

\subsection*{C.19.1 What Would Refute This Appendix's Claims}

The primary empirical claims of this appendix are:
\begin{enumerate}
  \item[P1.] GF16 KAT achieves BPB $< 2.30$ on WikiText-103 (Gate-1).
  \item[P2.] The champion configuration (cd91c45, seed 43) achieves
             BPB $\leq 2.24$ on WikiText-103.
  \item[P3.] The φ-derived β schedule reduces BPB relative to standard
             AdamW on the IGLA seed canon.
  \item[P4.] BPB is non-increasing along the ASHA rung trajectory in
             expectation (Theorem~\ref{thm:benchmark-monotonicity}).
\end{enumerate}

\noindent\textbf{Falsifying observation for P1.}
\emph{An independent reproduction of the GF16 KAT training run at
seed 47, step 81\,000, using the same architecture and dataset, that
produces BPB $\geq 2.30$ on WikiText-103 (sealed test split,
\texttt{STROBE\_SEED=1597}) would falsify P1.}

\noindent\textbf{Falsifying observation for P2.}
\emph{A reproduction of the champion run (commit \texttt{cd91c45},
seed 43, step 81\,000, $d_\text{model}=828$, $\eta=0.003$) that
produces BPB $> 2.24$ on WikiText-103 (sealed test, same strobe seed)
would falsify P2, provided the discrepancy exceeds the measurement
noise floor of $\pm 0.002$ BPB (three standard deviations above the
empirical run-to-run variability).}

\noindent\textbf{Falsifying observation for P3.}
\emph{A set of four runs over the IGLA seed canon $\{47,89,144,123\}$
using $\beta_1 = \varphi^{-1}$, $\beta_2 = \varphi^{-2}$ that
produces a seed-mean BPB $\geq$ the seed-mean BPB of the corresponding
runs with standard AdamW ($\beta_1=0.9$, $\beta_2=0.999$), with
$p < 0.05$ (paired $t$-test), would falsify P3.}

\noindent\textbf{Falsifying observation for P4.}
\emph{A set of ten runs started from fresh random initialisation under
$\Pi_\varphi$, in which the ASHA rung-0 survivor set has strictly
higher mean BPB at rung 1 than at rung 0 (i.e., training made BPB
worse on average after warmup), would falsify Lemma 2 and thereby
Theorem~\ref{thm:benchmark-monotonicity}.}
