\section*{B.1 Preamble}
\label{app:B-preamble}
\addcontentsline{toc}{section}{B.1 Preamble}

This appendix catalogues $60$ constants from the Trinity
S$^{3}$AI programme and the GOLDEN BRIDGE compendium that are
directly relevant to software implementation. Each constant has a
well-defined role in the GF16 arithmetic substrate, the IGLA RACE
scheduler, the VSA+AR module, or the Coq proof infrastructure. The
catalogue is split into five groups: algebraic core ($11$), hardware
($7$), runtime ($14$), neural-network ($16$), and verification ($12$).

\section*{B.7 Usage Notes}
\label{app:B-usage}
\addcontentsline{toc}{section}{B.7 Usage Notes}

Each constant in this catalogue is referenced by its ID (A1--A11,
H1--H7, R1--R14, N1--N16, V1--V12) in the Coq proof files under
\filepath{t27/proofs/} and in the assertion registry
\filepath{assertions/igla\_assertions.json}. The canonical floating-point
values (six decimal places) are computed using IEEE 754 binary64 and
verified against the GF16 binary16 representation in the INV-3 test
suite. Constants marked ``EXACT'' in the GOLDEN BRIDGE consolidated
table (FM-12) are not approximated; they are represented exactly in
the Lucas ring $\mathbb{Z}[\phi]$ and hence in the GF16 substrate.
