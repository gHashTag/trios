\section{Pre-Registration Protocol}\label{app_e:prereg-protocol}

Every statistical test in this dissertation was
pre-registered before any training run commenced.
The pre-registration record is stored in two
redundant locations: (a) the on-repository file
\filepath{igla\_assertions.json} under key
\texttt{stat\_test\_preregistration}, and (b) the
Open Science Framework (OSF) deposit at
\url{https://osf.io/golden-sunflowers}, registration
timestamp recorded by the OSF server.

\subsection{OSF Deposit
Structure}\label{app_e:osf-deposit}

The OSF project \texttt{golden-sunflowers} contains
the following components:

\begin{enumerate}
\item \textbf{Pre-registration form.} Completed
template specifying all parameters above, including
the choice of Welch \(t\)-test over pooled
\(t\)-test, the one-sided testing direction, and
the Bonferroni correction plan for multiple
comparisons.
\item \textbf{Sealed-seed manifest.} The list of
seven canonical seeds (five Fibonacci, two Lucas)
with their commitment hashes, matching the sealed-seed
protocol of Ch.13.
\item \textbf{Evaluation script.} The Python script
that computes BPB from model outputs, pinned by SHA-256
hash.
\item \textbf{Data access statement.} All training
and evaluation data are open-access; URLs are listed
in the deposit.
\end{enumerate}

\section{Reproducibility
Statement}\label{app_e:reproducibility}

All experiments can be reproduced by following the
steps in Appendix~D, using the canonical seeds
listed in the sealed-seed manifest, and the
evaluation partition defined by seed \(L_7 = 29\).
The FPGA bitstream for the QMTech XC7A100T is
included in Zenodo bundle B001
(\url{https://doi.org/10.5281/zenodo.19227867}).
The Coq proofs compile under Coq~8.18.0 with the
standard library only. The full source code is at
\filepath{gHashTag/t27} (canonical proofs) and
\filepath{gHashTag/trios} (infrastructure).
